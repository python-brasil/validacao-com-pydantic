# validacao-com-pydantic

Pydantic: do dicionário cru ao objeto com tipo garantido

Código do carrossel publicado no [@python_brasil](https://instagram.com/python_brasil).

## Como rodar

```bash
python main.py --help
```

```bash
pip install pydantic
python main.py
```

## O que este código NÃO faz

- é um exemplo didático, não um esquema de produção
- a checagem de e-mail é simplificada de propósito; em produção use `EmailStr` com `email-validator`
